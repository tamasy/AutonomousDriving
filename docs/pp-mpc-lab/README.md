# PP / MPC 経路追従ラボ

Pure Pursuit と MPC（モデル予測制御）の違いを、ブラウザ上で見比べる教材です。
上から見た走行画面で、パラメータを変えるとハンドルの切り方がどう変わるかを確認できます。

- 公開ページ: https://tamasy.github.io/AutonomousDriving/pp-mpc-lab/
- 動作環境: モダンブラウザ（PC・スマホ）。サーバー不要の静的HTML 1枚で動きます。

## モデルの前提
運動学的二輪モデル（ホイールベース 1.05 m）、ステアリング一次遅れ 0.12 s、制御周期 50 ms、車速一定。
MPCは制約なしの線形MPC（予測刻み 0.1 s、ステア遅れ込みのモデル）です。教材向けの簡易モデルです。
