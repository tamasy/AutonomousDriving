モデルの前提　運動学的二輪モデル（ホイールベース 1.05 m）、ステアリング一次遅れ 0.12 s、制御周期 50 ms、車速一定。MPCは制約なしの線形MPC（予測刻み 0.1 s、ステア遅れ込みのモデル）を毎周期、最小二乗で解いています。コースはどれも閉じた周回路で、8の字は交差点を直進します。教材向けの簡易モデルで、実車のタイヤ横すべりや入力制約は入れていません。

予測して最適化する

MPC（モデル予測制御）

緑の車

車のモデルで数秒先まで予測し、「ずれ」と「操作の大きさ」の合計が最小になる操作列を毎周期計算します。使うのは最初の一手だけ。点列が予測軌跡です。

min Σ ( Q·ずれ² + R·Δ操舵² )
