予測して最適化する

MPC（モデル予測制御）

緑の車

車の動きのモデルで数秒先までを予測し、「コースからのずれ」と「ハンドル操作の大きさ」の合計が最小になる操作の列を毎回計算します。使うのは最初の一手だけで、次の周期でまた計算し直します。画面の点列が予測した軌跡です。

min Σ ( Q·ずれ² + R·Δ操舵² )
目先だけ先まで見る
ずれを許さない操作を控える

モデルの前提：運動学的二輪モデル（ホイールベース 1.05 m）、ステアリング一次遅れ 0.12 s、制御周期 50 ms、車速一定。MPCは制約なしの線形MPC（予測刻み 0.1 s、ステア遅れ込みのモデル）を毎周期、最小二乗で解いています。教材向けの簡易モデルで、実車のタイヤ横すべりや入力制約は入れていません。
